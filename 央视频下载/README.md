# 央视频下载

提取央视网视频的 M3U8 地址，并按视频实际提供的资源选择清晰度；支持复制或打开地址，也可推送到本地 M3U8 下载器。

- **作者**：Augenstern-O
- **版本**：v1.0.0
- **适用网站**：[央视网](https://tv.cctv.com/)

## 功能说明

- 按视频实际资源列出可用清晰度，最高档位可能因视频而异，不保证所有视频都有 4K。
- 支持复制 M3U8 地址、在新标签页打开地址，或推送到本地下载器。
- 捕获视频后面板默认收起，仅显示右侧“视频下载”入口；鼠标移入入口即可展开，在入口或面板内移动时保持展开，移出整个区域后立即收起。
- H5E/enc 加扰流禁用推送；下载此类流需要支持 H5E 解密的下载器。

## 安装

1. 安装浏览器扩展：[Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)。
2. 在扩展中新建脚本，将 [央视频下载.js](./央视频下载.js) 的源码粘贴并保存。

## 使用

1. 打开央视网视频页；捕获到视频后，鼠标移入右侧“视频下载”入口展开面板，再选择清晰度并复制、打开或推送 M3U8 地址。
2. 使用推送功能前，先下载并启动 [M3U8 下载器](https://xyyx.lanzouw.com/i9hcAwj48be)。默认监听端口为 8787。
3. 若下载器实际端口不同，在油猴菜单选择“设置下载器推送端口”并填写实际端口。
