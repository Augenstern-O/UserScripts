# UserScripts

个人用户脚本集合，包含各种实用的浏览器脚本。

## 脚本列表

### 夸克网盘空间占用分析

分析夸克网盘当前目录空间占用，并使用 ECharts 矩形树图展示。

- **安装地址**: [Greasy Fork](https://greasyfork.org/zh-CN/scripts/564638)
- **详细说明**: [查看文档](./夸克网盘空间占用分析/README.md)
- **版本**: v1.0
- **更新日期**: 2026-01-31

**功能特性**:

- 使用异步请求，浏览器不卡死
- 实时显示当前扫描的文件夹
- 可随时中断扫描
- 支持从任意目录开始扫描
- 可视化图表展示

### 工业和信息化部行业标准全文下载

在工业和信息化部行业标准全文列表的预览按钮下方添加下载按钮，便于直接下载标准 PDF。

- **安装地址**: [直接安装](https://raw.githubusercontent.com/Augenstern-O/UserScripts/main/工业和信息化部行业标准下载/工业和信息化部行业标准下载.user.js) · [查看脚本源码](./工业和信息化部行业标准下载/工业和信息化部行业标准下载.user.js)
- **版本**: v1.0
- **适用网站**: [工业和信息化部行业标准全文公开系统](https://std.miit.gov.cn/)

**功能特性**:

- 在“预览”按钮下方自动添加“下载”按钮
- 自动获取标准预览 PDF 并触发浏览器下载

### 国家电网电量查询

在国家电网电量电费查询页恢复非智能交费签约户号的“近30天”切换按钮，使用页面原有逻辑查询电量。

- **安装方式**: [查看安装说明](./国家电网电量查询/README.md#安装)
- **详细说明**: [查看文档](./国家电网电量查询/README.md)
- **安装地址**: [直接安装](https://raw.githubusercontent.com/Augenstern-O/UserScripts/main/国家电网电量查询/国家电网电量查询.user.js)
- **脚本源码**: [国家电网电量查询.user.js](./国家电网电量查询/国家电网电量查询.user.js)
- **版本**: v1.0.0
- **适用网站**: [国家电网网上营业厅](https://www.95598.cn/osgweb/)

**功能特性**:

- 恢复“电量电费查询”页被隐藏的“近30天”选项
- 切换户号后自动恢复选项显示
- 无第三方依赖，脚本自身不发送网络请求

### 央视频下载

提取央视网视频的 M3U8 地址，并按视频实际提供的资源选择清晰度；支持复制或打开地址，也可推送到本地 M3U8 下载器。

- **安装方式**: [查看安装说明](./央视频下载/README.md#安装)
- **详细说明**: [查看文档](./央视频下载/README.md)
- **安装地址**: [直接安装](https://raw.githubusercontent.com/Augenstern-O/UserScripts/main/央视频下载/央视频下载.user.js)
- **脚本源码**: [央视频下载.user.js](./央视频下载/央视频下载.user.js)
- **作者**: Augenstern-O
- **版本**: v1.0.0
- **适用网站**: [央视网](https://tv.cctv.com/)

**功能特性**:

- 按视频实际资源列出可用清晰度，最高档位可能因视频而异，不保证所有视频都有 4K
- 支持复制 M3U8 地址、在新标签页打开地址，或推送到本地下载器
- 捕获视频后面板默认收起，仅显示右侧“视频下载”入口；鼠标移入入口展开，在入口或面板内移动时保持展开，移出整个区域后立即收起
- H5E/enc 加扰流禁用推送；下载此类流需要支持 H5E 解密的下载器

## 如何使用

1. 安装浏览器扩展：[Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)
2. 按上方对应脚本的安装地址或安装说明进行安装；使用 GitHub 安装时请打开脚本的 Raw 文件地址，打开 GitHub 源码展示页不会触发安装
3. 访问对应网站即可使用
