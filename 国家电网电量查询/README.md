# 国家电网电量查询

在国家电网电量电费查询页恢复非智能交费签约户号的“近30天”切换按钮，使用页面原有逻辑查询电量。

- **作者**：[@Augenstern-O](https://github.com/Augenstern-O)
- **版本**：v1.0.0
- **适用网站**：[国家电网网上营业厅](https://www.95598.cn/osgweb/)
- **脚本源码**：[国家电网电量查询.js](./国家电网电量查询.js)

## 功能特性

- 恢复“电量电费查询”页被隐藏的“近30天”选项
- 切换户号后，自动修正页面再次隐藏按钮的情况
- 仅在地址路径包含 `electricityCharge` 的页面执行显示修正
- 使用网站原有查询与展示逻辑，脚本自身不发送网络请求
- 无第三方依赖，无需额外脚本权限

## 安装

1. 安装浏览器扩展：[Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)。
2. 打开[脚本源码](./国家电网电量查询.js)，复制完整内容。
3. 在脚本管理器中新建脚本，用复制的内容替换默认模板，保存并启用。
4. 打开或刷新[国家电网网上营业厅](https://www.95598.cn/osgweb/)。

如果曾安装旧版“95598 电量查询：解锁‘近30天’按钮”，请先停用或删除旧版，再安装本版，避免两个脚本同时运行。新版统一了脚本名称和命名空间，脚本管理器可能将其识别为另一份脚本。

## 使用方法

1. 登录国家电网网上营业厅，选择已绑定的用电户号。
2. 进入“电量电费查询”页面。
3. 等待“近30天”选项显示，点击后查看网站返回的电量数据。
4. 切换户号后，脚本会在后续检查中恢复被隐藏的选项，无需手动重复操作。

## 技术说明

- 脚本匹配 `https://www.95598.cn/osgweb/*`，在页面空闲时启动。
- 每隔 500 毫秒检查一次当前页面路径和查询组件。
- 从 `#main` 容器读取 Vue 实例，仅在其 `show30DayRadio` 属性为 `false` 时设为 `true`。
- 轮询用于处理页面异步加载及切换户号后重新隐藏按钮的情况。
- 使用 `@grant none`，未调用脚本管理器的特权接口，也未读取或保存账号凭据。

## 常见问题

### 安装后没有看到“近30天”

确认脚本已启用，刷新页面后重新进入“电量电费查询”。脚本依赖页面的 `#main` 容器和 `show30DayRadio` 属性，网站改版可能导致显示修正失效。

### 按钮显示了，但没有查询到数据

脚本只恢复按钮显示。数据是否可查询、覆盖哪些日期以及更新时间，均以当前户号和网站实际返回为准。

### 是否会开通智能交费或修改户号信息？

脚本只修改当前页面组件的显示属性，不执行签约、缴费或户号信息修改操作。点击选项后，电量查询由网站自身完成。
